1) FLEET COMMAND CENTER

- Vehicles Online / Offline

- High-Risk Alerts
- Equipment Faults
- Overdue Maintenance
- Active Safety Events
- Vehicles Running > X minutes
- Vehicles with Lift Failure Today

2) ADAPTIVE EQUIPMENT MONITORING

Per vehicle view must show:
- Lift cycle count
- Last usage session
- Session success/failure rate
- Fault codes
- Interrupted cycles
- Door open/close states
- Battery/voltage health (if available)
- Firmware version
- Connectivity status

EquipmentSessions table must track:
- start_time
- end_time
- duration
- session_type (raise/lower/etc)
- success/failure
- error_code
- signal_strength
- voltage metrics

----------------------------------------

3) VEHICLE SAFETY MONITORING

Track:
- Ignition on/off
- Idle duration
- Engine running status
- Movement detection
- Door status
- After-hours activity
- Battery irregularities

Generate alerts for:
- Engine running > configurable threshold
- Ignition on + no movement
- Vehicle active after scheduled hours
- Prolonged idle in enclosed risk scenarios
- Low battery risk

4) PASSENGER SAFETY ALERT SYSTEM

Generate real-time alerts for:
- Lift malfunction before transport
- Equipment failure during loading/unloading
- Offline device > X minutes
- Overcurrent or stall events
- Repeated session failures
- Critical fault codes

Alert routing rules:
- Assignable to roles
- Email (log only in dev)
- In-app notification center
- Escalation tiers

- Overdue alerts

- Pre-maintenance failure rate
- Post-maintenance performance
